# Wedding Invitation Book

A mobile-first cinematic wedding invitation built as a physical-style page-turning book.

## Included in the first foundation

- Realistic CSS 3D page-turn animation
- Mobile swipe navigation
- Desktop previous/next controls
- Responsive wedding-book layout
- Cover, couple, story, events, venue and gallery pages
- Premium/elegant visual direction
- Placeholder wedding content ready to replace
- WhatsApp RSVP button placeholder
- Music control UI ready for the final wedding track
- Reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Next customization

Replace the placeholder names, dates, venue, photos, WhatsApp number and music track. The page structure is intentionally separated from the wedding data so the design can be refined without rebuilding the whole experience.
